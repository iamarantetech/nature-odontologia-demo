# Nature Odontologia — site demonstrativo

Demonstração de site criada por **IAmarante Tech** para a Nature Odontologia (Gama – DF).

- Página única em HTML, sem dependências: abra o `index.html` no navegador.
- Conteúdo provisório (fotos, logo e textos retirados do perfil público da clínica, avaliações reais do Google).
- A página tem `noindex` para não aparecer em buscadores enquanto for demonstração.
